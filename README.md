# 먼작귀 서바이버즈

먼가 작고 귀여운 녀석(ちいかわ) **비공식 · 비영리 팬게임**. 뱀파이어 서바이버즈류 생존 게임으로, 게임 규칙은 덩크 서바이버(nba-kor.github.io/survive)에서 가져왔고 그림 · 캐릭터 · 스킬은 먼작귀 세계로 새로 만들었습니다. 캐릭터 · 토벌 대상 생김새는 나무위키 「먼작귀/등장인물」 문서의 설명을 참고해 코드로 그렸습니다.

- 플레이: https://chii-ka-wa.github.io/
- 원작: 「ちいかわ」 © ナガノ

## 게임

- 캐릭터 8명: 치이카와(사스마타) · 하치와레(기타) · 우사기(토벌봉) · 모몽가(내놔!) · 쿠리만쥬(건배!) · 랏코(일섬) · 시사(라멘 국물) · 카니(회색 사스마타). 시작 스킬과 특성이 서로 다릅니다.
- 스킬 14종(최고 Lv 8) · 아이템 13종(최고 Lv 5) · 시너지 7쌍. 레벨 업 상자에서 리롤 · 스킵 · 제외를 쓸 수 있고 잭팟이 터지기도 합니다.
- 토벌 대상: 고블린 · 꼬마 키메라 · 큰 키메라 · 가시 키메라 · 황금 고블린 · 고블린 돌격대
- 보스: 고블린 대장 · 데카츠요 · 거대 키메라 · 아노코(20분, 「커다란 토벌」) → **25분에 최종보스 세이렌 + 인어 3마리**. 세이렌을 쓰러뜨리면 클리어입니다.
- 게임 안 「도감」에서 전부 볼 수 있습니다.

## 파일

| 파일 | 내용 |
|---|---|
| `index.html` | 페이지 · 스타일 |
| `game.js` | 게임 전부. 맨 위 「표」(CHARS · WEAP · SYN · PASS · FOES · BOSS · PLAN)만 고쳐도 캐릭터 · 스킬 · 보스 일정이 바뀝니다 |
| `test/smoke.cjs` | 헤드리스 브라우저로 처음 화면부터 클리어까지 빨리 돌려 보는 점검 |

빌드는 없습니다. 기록은 브라우저 localStorage(`mjg.v1`)에만 저장되고 서버 · DB는 없습니다.

## 로컬 실행 · 점검

```sh
python3 -m http.server 8765
# 다른 터미널에서 — playwright 가 설치된 node_modules 경로
NODE_PATH=/path/to/node_modules node test/smoke.cjs
```

## 배포

`main` 에 푸시하면 GitHub Pages(`chii-ka-wa.github.io`)에 그대로 올라갑니다.
