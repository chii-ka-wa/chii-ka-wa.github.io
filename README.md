# 먼작귀 서바이버즈

먼가 작고 귀여운 녀석(ちいかわ) **비공식 · 비영리 팬게임**. 뱀파이어 서바이버즈류 생존 게임으로, 게임 규칙은 덩크 서바이버(nba-kor.github.io/survive)에서 가져왔고 그림 · 캐릭터 · 스킬은 먼작귀 세계로 새로 만들었습니다. 캐릭터 · 토벌 대상 생김새는 나무위키 「먼작귀/등장인물」 문서의 설명을 참고해 코드로 그렸습니다.

- 플레이: https://chii-ka-wa.github.io/
- 원작: 「ちいかわ」 © ナガノ

## 게임

- 캐릭터 8명: 치이카와(사스마타) · 하치와레(기타) · 우사기(토벌봉) · 모몽가(내놔!) · 쿠리만쥬(건배!) · 랏코(일섬) · 시사(라멘 국물) · 카니(회색 사스마타). 시작 스킬과 특성이 서로 다릅니다.
- 스킬 14종(최고 Lv 8) · 아이템 13종(최고 Lv 5) · 시너지 7쌍. 레벨 업 상자에서 리롤 · 스킵 · 제외를 쓸 수 있고 잭팟이 터지기도 합니다.
- 토벌 대상(나무위키 「몬스터(먼작귀)」 참고): 고블린 · 초록 곤충 · 꼬마 키메라 · 꼬마 풍뎅이 · 별똥별 · 분홍 키메라 · 가면 키메라 · 복어 · 문어 괴물 · 아르바이트생 괴물 · 황금 고블린 · 고블린 돌격대
- 보스: 고블린 대장 · 데카츠요 · 가위바위보 · 거대 키메라 · 요리사 괴물 · 아노코(20분, 「커다란 토벌」) → **25분에 최종보스 세이렌 + 인어 3마리**. 세이렌을 쓰러뜨리면 토벌 성공. 29분까지 못 쓰러뜨리면 **검은 별똥별**(쓰러뜨릴 수 없다)이 쫓아오고, 30:00까지 도망치면 생존 클리어입니다. 타이머 아래에 다음 보스까지 남은 시간이 나옵니다.
- 도와주는 친구들(선택 캐릭터 아님): 🎫 꿀맛 페스티벌 티켓을 먹으면 파자마 파티즈가 10초 동안 공연(음표 충격파 · 쿨타임 -25%), 🔋 건전지를 먹으면 한잎이 · 두잎이가 12초 동안 곁을 지킨다(날아오는 것을 막고 밀쳐 냄). 보스가 하나씩 떨어뜨린다.
- 난이도(캐릭터 고르는 화면에서, 쉬움이 기준): 🌱 쉬움 · ⭐ 보통(쉬움보다 적 체력 +33% · 경험치 -17% · 줍는 것 -25%) · 🔥 어려움(+67% · -33% · -50%, 원래 토벌 그대로). 배수는 `game.js`의 `DIFF` 표에 있고 설명 글은 배수에서 저절로 만들어집니다. 멀리서 쏘는 일반 몬스터(가면 키메라 · 복어 · 문어)는 어려움에서만 나옵니다. 기록은 난이도마다 따로(예전 기록은 어려움).
- 날아오는 것은 크게, 빨간 테와 꼬리를 달아 보석과 구별되게 그립니다. 쏘기 직전에는 머리 위에 빨간 ! 가 뜨고, 겨누는 것은 조준선도 나옵니다.
- 게임 안 「도감」에서 전부 볼 수 있습니다.
- 처음 화면 「패치노트」에서 바뀐 점을 볼 수 있습니다. 새 기록은 `game.js`의 `PATCH` 맨 위에 날짜와 함께 넣으면, 아직 안 본 사람에게 NEW 가 뜹니다.

## 파일

| 파일 | 내용 |
|---|---|
| `index.html` | 페이지 · 스타일 |
| `game.js` | 게임 전부. 맨 위 「표」(CHARS · WEAP · SYN · PASS · FOES · BOSS · PLAN)만 고쳐도 캐릭터 · 스킬 · 보스 일정이 바뀝니다 |
| `test/smoke.cjs` | 헤드리스 브라우저로 처음 화면부터 클리어까지 빨리 돌려 보는 점검 |

빌드는 없습니다. 기록은 브라우저 localStorage(`mjg.v1`)에만 저장되고 서버 · DB는 없습니다.

## 소리

파일 없이 웹 오디오로 직접 만든다(`game.js` 의 `SND`). 첫 클릭 · 키 · 터치에 켜진다. 오른쪽 위 🔊 단추를 누르면 가운데 창에서 배경음 · 효과음 크기를 따로 조절한다(0 이면 끔, 이 브라우저에 기억). 게임 중에 열면 멈추고, 닫으면(닫기 · 바깥 · Esc) 이어서.

- 배경음악: 직접 지은 두 곡 — 풀밭(처음 화면 · 토벌), 세이렌(최종보스 · 검은 별똥별). 일시정지하면 작아진다
- 효과음: 맞힘 · 쓰러뜨림 · 경험치 · 레벨 업 · 보물상자 · 다침 · 보스 등장 · 검은 별똥별 · 끝
- 캐릭터 목소리: 캐릭터마다 높이 · 음색이 다른 삐약 소리(시작 · 레벨 업은 기쁘게, 다치면 아프게, 쓰러지면 울음). 원작 성우 음성은 쓰지 않는다

## 검색 · 공유

- `index.html` 머리말: 제목 · 설명 · 키워드 · canonical · robots, 공유 미리보기(Open Graph · X 카드), 아이콘, 검색 엔진용 구조화 데이터(JSON-LD `VideoGame`), 자바스크립트가 꺼진 곳을 위한 `<noscript>` 소개
- `og.png`(1200×630 공유 썸네일) · `icon-512.png` · `apple-touch-icon.png`(180) · `favicon.png`(64) — 게임 속 직접 그린 캐릭터로 `test/og.cjs` 가 만든다(그림을 고치면 다시 실행)
- `robots.txt`(사이트맵 위치) · `sitemap.xml`(내용을 바꾸면 `lastmod` 날짜를 고친다) · `site.webmanifest`(홈 화면에 추가할 때 이름 · 아이콘)

검색 등록(소유 확인 코드는 각 사이트에서 받아 `index.html` 머리말에 한 줄 넣는다)

1. 구글 서치 콘솔 — 속성 추가 → URL 접두어 `https://chii-ka-wa.github.io/` → 「HTML 태그」 → `<meta name="google-site-verification" content="…">` 를 넣고 푸시 → 확인 → 「Sitemaps」에 `sitemap.xml` 제출
2. 네이버 서치어드바이저 — 웹마스터 도구 → 사이트 등록 `https://chii-ka-wa.github.io` → 「HTML 태그」 → `<meta name="naver-site-verification" content="…">` 를 넣고 푸시 → 소유 확인 → 요청 › 사이트맵 제출(`https://chii-ka-wa.github.io/sitemap.xml`) · robots.txt 확인 · 웹 페이지 수집 요청
3. 카카오톡 미리보기가 예전 것으로 보이면 — 카카오 개발자 「공유 디버거」에서 주소를 넣고 캐시 초기화
