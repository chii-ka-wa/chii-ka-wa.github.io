먼가 작고 귀여운 녀석(ちいかわ) **비공식 · 비영리 팬게임**. 뱀파이어 서바이버즈류 생존 게임으로, 게임 규칙은 덩크 서바이버(nba-kor.github.io/survive)에서 가져왔고 그림 · 캐릭터 · 스킬은 먼작귀 세계로 새로 만들었습니다. 캐릭터 · 토벌 대상 생김새는 나무위키 「먼작귀/등장인물」 문서의 설명을 참고해 코드로 그렸습니다.

## 계정 · 무한 랭킹(Supabase Auth)

카카오 · 구글 로그인(`supabase/account.sql`). 로그인하면 저장(save 통째)을 `saves` 표에도 두고(기기마다 `mjg.sync` — 둘 다 바뀌었으면 「이 기기 / 내 계정」을 고르는 창), 무한 모드 기록을 `ranks` 에 올립니다(닉네임은 게임 안에서 — `players`, 처음은 바로 · 그다음은 하루에 한 번 변경 · 금지어 · 대소문자 무시 중복 검사는 서버).

- 랭킹 순서: 단계 ↓ → 잡은 보스 ↓ → 버틴 시간 ↓ → 마지막 보스를 잡은 때 ↑ → 먼저 세운 기록(2026-11-20 — 예전엔 잡은 때가 버틴 시간보다 앞이었다)(새 판이 이 순서로 더 좋을 때만 기록을 바꾼다). 전체 TOP 100(사람마다 최고 하나) · 캐릭터별 TOP 10(`top_ranks`), 내 순위(`my_rank`). 겨울 · 풀밭 따로(`ranks` 기본 키 (uid, ch, winter) · `top_ranks(only_ch, on_winter)` — 랭킹 화면 제목 밑 맵 고르기, 기본 겨울 · 맵마다 사람마다 최고 하나). 줄마다 그 판에 입은 의상 · 무기 스킨(`ranks.outfit · wskin`)과 플레이한 언어 국기(`ranks.lang` — 다섯 말만, 그 밖은 비워서 받는다 · 예전 기록은 없음)
- 서버 검증(`submit_rank`): 무한 판을 시작할 때 `start_run` 으로 시각을 남기고(로그인한 판만), 올릴 때 「실제 흐른 시간 ≥ 기록 ÷ 3(배속)」(모자라면 'fast' — 거절만. 무한 2배속이 된 판 `v ≥ 2026-11-20#7` 부터는 ÷ 2 · 날짜와 번호를 나눠 비교. 정지 줄 ÷ 3 − 30 은 그대로 — 캐시에 남은 예전 판 · 기획) · 시작한 지 6시간 안 · 단계와 시간이 맞는지 · 같은 판은 한 번. 브라우저 게임이라 손쉬운 위조만 막는다 — 이상한 기록은 대시보드에서 `delete from ranks where …`

  - 추가 검사: 보스 수 ≤ 그 단계까지 나올 수 있는 수(25분 전 6, 단계 L 이면 4 + 15L, +2 여유) · 보스 ≥ 종류별 합 → 정지, 첫 스킬이 캐릭터 무기가 아니면 거절. `ranks.real` = 시작 → 올리기 실제 초(살펴보기용). 살펴보기: `supabase/inspect.sql`(의심 목록 · 최근 신호 · 지금 규칙으로 다시 본 기록 · 차단 중)
  - 보상금: 계정 저장이 바뀔 때(`saves_guard` — 처음 올리는 것은 빼고) 지난 저장부터 흐른 서버 시간(3시간까지) × 분당 2,000 + 6,000 보다 많이 늘면 기록 + 랭킹에서 빼 둔다(`bans` 에 coin — 저장은 그대로 받는다). 저장 지우기 권한은 없다(지우고 새로 넣어 검사를 피하지 못하게)

  - 정지된 계정은 게임이 로그아웃시키고 처음 화면에 번호(`suspended()`), 로그인 없는 판은 그대로. IP 가 막히면 열 때 묻고(`blocked()`, 기다리지 않음 · 서버가 안 되면 연다) 게임 대신 안내 화면(번호 · 풀리는 때). GitHub Pages 라 진짜 네트워크 차단은 아니다 — 랭킹 · 통계는 서버도 막는다
  - ★ 잘못 막혔다는 문의(번호 = `bans.id`): `delete from bans where id = <번호> or uid = (select uid from bans where id = <번호>);`
  - 직접 차단(`bans`): 차단되면 랭킹 · 익명 통계에서 빠지고, IP 차단이면 사이트도 못 연다. 계정 정지 — `insert into bans (uid, stop, reason) values ('<uid>', true, '무적');` 계정 차단을 먼저 — `insert into bans (uid, reason) values ('<uid>', '무적');` IP 차단은 기간제로 — `insert into bans (ip_h, reason, until) values ('<ip_h>', '…', now() + interval '7 days');` (통신사 · 학교는 여러 사람이 IP 하나를 같이 쓴다. 원래 IP 를 알면 `ip_hash('1.2.3.4')`). 풀기 `delete from bans where id = …;`
- 로그인 중에는 익명 통계(`report_run`, 계정 없이)를 늘 보낸다 — 처음 화면 「보내지 않기」 자리에 「로그인 중에는 통계를 보내요」. 방문 통계(GA)는 그대로 토글 · 추적 거부를 따른다. 로그인 안 하고 통계를 끄면 무한 모드는 「토벌 시작!」에서 켤지 묻는다
- 계정 지우기: 계정 메뉴 맨 아래 작은 글씨 → 닉네임(없으면 「지우기」)을 똑같이 써야 눌린다 → `delete_me()` — `auth.users` 를 지우면 저장 · 닉네임 · 랭킹이 따라 지워지고, 그 계정의 부정 플레이 기록 · 로그인 기록도. 진행 중인 차단만 끝날 때까지 남긴다. 이 기기 기록은 그대로
- 개인정보: 이메일 · 이름 · 사진은 남기지 않는다 — `auth.users` · `auth.identities` · 로그인 기록(`audit_log_entries`) · 세션에 들어오는 것을 트리거(`mjg_scrub`)가 넣기 · 고치기 때마다 비운다(남는 것은 제공자 사용자 번호 ↔ 계정 ↔ 닉네임). 그래서 같은 이메일이어도 카카오 · 구글 계정은 따로따로
- 지울 때가 된 것(`gc()`, pg_cron 한 시간마다): 부정 플레이 기록 90일(차단 중인 계정 · IP 것은 차단이 끝날 때까지) · 끝난 차단 · 익명 통계 횟수 제한용 IP 해시 1시간 · 끝난 쿠폰의 사용 기록(끝나고 7일 뒤). 처리방침과 같아야 한다
- 쿠폰(`account.sql` 8번 · game.js `COUPON` · `couponBox`): 계정 메뉴 「쿠폰 입력」(로그인한 사람만) → `redeem(code)` — 띄어쓰기 · 대소문자 무시(NFKC), `coupons` 에 쿠폰(id) 하나에 이름 여럿(출시 기념 `launch` 1,000 · 다섯 말 이름 · 2026-12-20 23:59:59 KST까지). 계정마다 한 번(`coupon_uses`) + 계정 저장에 받은 표시 `save.cpn` 이 있어도 받은 것(탈퇴 → 재가입으로 또 받기 막기 — 개인정보를 더 남기지 않고). 정지 · 차단이면 못 받는다. 받으면 게임이 그 자리에서 보상금 · `save.cpn` · 저장 → 바로 계정으로. `saves_guard` 는 받은 표시가 계정 저장에 처음 올라올 때 그 쿠폰 몫을 한 번 봐주고 `coupon_uses.synced` 를 켠다(사용 기록이 있을 때만 · 시간과 상관없이). 응답을 못 받았으면(서버엔 기록 · 저장엔 아직 없음) 다시 눌러 받는다 — synced 가 아니면 다시 ok, 게임은 이 기기 저장에 표시가 없을 때만 더한다. 기간 동안 아직 안 받았으면 계정 단추에 점. 새 쿠폰은 `coupons` 에 줄 추가(끝나는 때는 game.js `COUPON` · 패치노트 날짜와 같게)
- 이용약관: 게임 안 창(`terms()` — 처음 화면 맨 아래 · 로그인 창 링크), 주소 `https://chii-ka-wa.github.io/?terms`. 처음 로그인(새 계정)과 동의 버전이 올라간 뒤(`TERMS_VER` — 불리한 변경 때만) 첫 로그인에 동의 창(`termsBox` — 단추 하나, 체크박스 없음, 바깥 · Esc 로 안 닫힘). 동의는 `terms_ok`(시행일 · 시각, `agree` · `agreed`), 새 계정이 동의하지 않으면 계정을 지우고(`delete_me`) 로그아웃, 기존 계정은 로그아웃만. 개인정보는 동의가 아니라 처리방침으로 알린다(로그인 정보는 서비스에 꼭 필요한 정보). 약관을 바꾸면 `TERMS_DAY`(시행일)를 바꾸고, 이용자에게 불리한 변경일 때만 `TERMS_VER`(동의 버전 — 7일 전부터 알리고 다음 로그인에 다시 묻는다)도 올린다 — 9번 「고의 또는 중대한 과실이 없는 한」은 남길 것
- Google 로그인: 진짜 주소에선 Google 공식 단추(Google Identity Services — `gisButton` → ID 토큰을 `/auth/v1/token?grant_type=id_token` 으로, nonce). 리디렉트(supabase.co 를 거침)는 쓰지 않는다 — 구글 화면에 앱 이름을 보이려면 브랜드 인증이 필요하고, 인증은 승인된 도메인을 모두 소유 확인해야 해서 supabase.co 를 뺀다. 클라이언트 ID(`GOOGLE_ID`)는 공개 값
- 개인정보 처리방침: 게임 안 창(`privacy()` — 처음 화면 맨 아래 링크), 주소 `https://chii-ka-wa.github.io/?privacy`(영어 `?lang=en&privacy`) — 카카오 · 구글 콘솔의 개인정보처리방침 주소 칸에 넣는다. 고치면 `PRIVACY_DAY`(시행일)도
- 토큰은 `localStorage['mjg.auth']`(Supabase REST 를 `fetch` 로 직접 — 라이브러리 없음). 점검: `node test/smoke.cjs` 의 `acct`(서버를 흉내 낸다), SQL 은 Postgres 컨테이너에서 따로 돌려 봤다

## 소리

파일 없이 웹 오디오로 직접 만든다(`game.js` 의 `SND`). 첫 클릭 · 키 · 터치에 켜진다. 오른쪽 위 소리 단추를 누르면 가운데 창에서 배경음 · 효과음 크기를 따로 조절한다(0 이면 끔, 이 브라우저에 기억). 게임 중에 열면 멈추고, 닫으면(닫기 · 바깥 · Esc) 이어서.

- 배경음악: 직접 지은 두 곡 — 일렉 팝(처음 화면 · 토벌, 16마디 — 4비트 킥에 출렁이는 베이스 · 아르페지오 · 리드), 세이렌(최종보스 · 검은 별똥별 — 네모파 칩튠). 일시정지하면 작아진다
- 토벌 중 일렉 팝은 같은 곡을 캐릭터마다 다른 악기로(`KIT`): 처음 화면 일렉 신스 · 치이카와 오르골 · 하치와레 어쿠스틱 기타 · 우사기 록 기타 · 모몽가 칩튠 · 쿠리만쥬 일렉 피아노 · 랏코 피리 · 시사 산신 · 카니 마림바
- 효과음: 맞힘 · 쓰러뜨림 · 경험치 · 레벨 업 · 보물상자 · 다침 · 보스 등장 · 검은 별똥별 · 끝
- 캐릭터 목소리: 캐릭터마다 높이 · 음색이 다른 삐약 소리(시작 · 레벨 업은 기쁘게, 다치면 아프게, 쓰러지면 울음). 원작 성우 음성은 쓰지 않는다
