# 먼작귀 서바이버즈

먼가 작고 귀여운 녀석(ちいかわ) **비공식 · 비영리 팬게임**. 뱀파이어 서바이버즈류 생존 게임으로, 게임 규칙은 덩크 서바이버(nba-kor.github.io/survive)에서 가져왔고 그림 · 캐릭터 · 스킬은 먼작귀 세계로 새로 만들었습니다. 캐릭터 · 토벌 대상 생김새는 나무위키 「먼작귀/등장인물」 문서의 설명을 참고해 코드로 그렸습니다.

- 원작: 「ちいかわ」 © ナガノ

## 게임

- 캐릭터 8명: 치이카와(사스마타) · 하치와레(기타) · 우사기(토벌봉) · 모몽가(내놔!) · 쿠리만쥬(건배!) · 랏코(일섬) · 시사(라멘 국물) · 카니(헌책 날리기 — 가까운 적 쪽으로 책장이 부채꼴로 차례로). 시작 스킬과 특성이 서로 다릅니다.
- 스킬 16종(최고 Lv 8) · 아이템 13종(최고 Lv 5) · 시너지 8쌍(헌책 날리기 + 헌책 더미 = 「카니의 헌책방」 — 더미는 지나온 자리에 쌓이는 덫, 안 무너진 것은 12개까지). 레벨 업 상자에서 리롤 · 스킵 · 제외를 쓸 수 있고 잭팟이 터지기도 합니다.
- 토벌 대상(나무위키 「몬스터(먼작귀)」 참고): 고블린 · 초록 곤충 · 꼬마 키메라 · 꼬마 풍뎅이 · 별똥별 · 분홍 키메라 · 가면 키메라 · 복어 · 문어 괴물 · 아르바이트생 괴물 · 황금 고블린 · 고블린 돌격대
- 보스: 고블린 대장 · 데카츠요 · 가위바위보 · 거대 키메라 · 요리사 괴물 · 아노코(20분, 「커다란 토벌」) → **25분에 최종보스 세이렌 + 인어 3마리**(세이렌은 명암 · 진주 허리띠 · 결 있는 큰 지느러미로 공들여 그리고, 게임 속에서는 등 뒤 빛과 맴도는 음표 셋). 세이렌을 쓰러뜨리면 토벌 성공. 29분까지 못 쓰러뜨리면 **검은 별똥별**(쓰러뜨릴 수 없다)이 쫓아오고, 30:00까지 도망치면 생존 클리어입니다. 타이머 아래에 다음 보스까지 남은 시간이 나옵니다.
- 도와주는 친구들(선택 캐릭터 아님): 꿀맛 페스티벌 티켓을 먹으면 파자마 파티즈가 10초 동안 넓게 돌며 공연(가까운 적에게 음표 · 0.6초마다 음표 충격파 · 쿨타임 -25%), 건전지를 먹으면 한잎이 · 두잎이가 6초 동안 지킨다(가장 가까운 다가오는 것 — 없으면 가까운 적 — 쪽으로 돌아 서서 막고 세게 밀쳐 냄). 보스가 하나씩 떨어뜨린다.
- 난이도(캐릭터 고르는 화면에서, 쉬움이 기준): 쉬움 · 보통(쉬움보다 적 체력 +33% · 경험치 -17% · 줍는 것 -25%) · 어려움(+67% · -33% · -50%, 원래 토벌 그대로). 배수는 `game.js`의 `DIFF` 표에 있고 설명 글은 배수에서 저절로 만들어집니다. 멀리서 쏘는 일반 몬스터(가면 키메라 · 복어 · 문어)는 어려움에서만 나옵니다. 기록은 난이도마다 따로(예전 기록은 어려움).
- 피해야 할 적의 바닥 공격(경고 원)은 칠한 색과 상관없이 빨간 점선 테두리 + 가운데 ! — 내 스킬 장판(라멘 노랑 · 카레 겨자)은 빨강 · 주황을 쓰지 않는다. 보스 체력 배수는 `BOSS_HP`. 체력이 낮으면 화면 가장자리만 붉게(깜빡이지 않음)
- 날아오는 것은 크게, 빨간 테와 꼬리를 달아 보석과 구별되게 그립니다. 쏘기 직전에는 머리 위에 빨간 ! 가 뜨고, 겨누는 것은 조준선도 나옵니다.
- 토벌 보상금 · 영구 강화 상점: 판이 끝나면 버틴 시간(10초에 1) · 처치(200에 1) · 보스(15) · 클리어(60)에 난이도 배수(`DIFF.coin` — 쉬움 1 · 보통 1.25 · 어려움 1.5)를 곱한 보상금(`bounty`). 처음 화면 「상점」에서 `SHOP` 표의 영구 강화를 산다(n 번째 칸 = cost × n). 한 칸이 같은 아이템 한 레벨의 1/5쯤이라 다 사도 아이템 한 레벨 몫 — 판의 밸런스를 지키려고 일부러 작게. 이 브라우저(`save.coin` · `save.up`)에만
- 업적(`ACH` 표 — 처음 화면 「업적」): 12가지 × 동 · 은 · 금. 쉬운 것은 횟수를 많이(`tiers`), 어려운 것은 적게. 판이 끝날 때 `achieve()` 가 `save.ach` 에 더한다(판 수 · 클리어한 캐릭터는 원래 기록에서). 금메달 하나마다 토벌 보상금 +1%(`bounty`). 메달은 `medalSpr` 가 리본 · 판 · 가운데 그림(아이콘이나 캐릭터 그림)으로 직접 그린다
- 게임 안 「도감」에서 전부 볼 수 있습니다.
- 맞으면 0.8초 무적 + 둘레를 밀쳐 냄. 레벨 업은 체력 10% 회복 · 닫으면 둘레를 비우고 1.2초 무적. 보스 · 중간보스는 `RAGE_T`(60초) 넘게 살아 있으면 화낸다(빨라지고 기술 자주). 보스 · 중간보스를 쓰러뜨리면 쉬어 가는 창
- 스킬별 준 피해(`G.dmg` — 피해를 줄 때의 `SRC`, 쏜 것은 `src`)를 일시정지 · 보스 격파 · 결과 화면에 막대로. 스킬이 나가면 HUD 아이콘이 반짝. 스킬마다 `how`(하는 일 한 줄)가 레벨 업 카드에
- 일시정지에서 화면 배율 75~140%(`save.zoom`, 이 브라우저에 기억). `size()` 가 배율을 `SC` 에 곱하고, 그려 두는 그림의 픽셀 밀도 `K`(최대 4)도 배율에 맞춰 다시 그려 확대해도 흐려지지 않는다
- 자동 화질(`autoQ` · `LQ`): 판 처음(5~90초)의 가장 빠른 프레임 시간을 기준으로 나중에 1.6배(적어도 26ms) 넘게 느려지면 4초 간격으로 한 단계씩 — 픽셀 ×0.8 → ×0.62(화면 1배 밑으로는 안 내림), 작은 적 그림자 빼기, 피해 숫자 30개까지. 그림만 바뀌고 규칙은 그대로, 판마다 다시 0. 20분 넘어 적이 320마리일 때(지금 한도는 `MAX_FOES` 240 — 넘친 몫은 `G.crowd`(최대 ×1.33, 예전 320 몫)로 보통 적 피 · 경험치에 곱해 난이도는 그대로) 그리기가 프레임의 대부분(게임 계산은 2.5ms)이라 픽셀 수가 가장 크게 듣는다(점검 기기에서 95 → 63 → 51ms)
- 아이콘(스킬 · 아이템 · 난이도 · 소리 단추 등)은 이모지 대신 코드로 직접 그립니다(`game.js` 의 `ICO`) — 기기마다 다르게 보이지 않게. 캔버스에는 `icoSpr(id)`, 메뉴에는 `ic(id)`
- 처음 화면 「패치노트」에서 바뀐 점을 볼 수 있습니다. 새 기록은 `game.js`의 `PATCH` 맨 위에 날짜와 함께 넣으면, 아직 안 본 사람에게 NEW 가 뜹니다.

## 익명 플레이 통계(Supabase)

판이 끝나면(쓰러짐 · 클리어 · 30분 생존 · 그만두기) `runs` 표에 한 줄 — 캐릭터 · 난이도 · 결과 · 버틴 시간 · 레벨 · 처치 수 · 쓰러뜨린 것 · 그때의 보스 · 스킬 · 휴대폰 여부 · 영구 강화 칸 수(`up`) · 게임 버전. 이름 · 기기 정보처럼 사람을 알 수 있는 것은 보내지 않습니다.

- 끄기: 처음 화면 아래 「보내지 않기」(이 브라우저에 기억). 브라우저의 추적 거부(GPC · Do Not Track)도 따릅니다
- `chii-ka-wa.github.io` 에서만 보냅니다 — 로컬 실행 · 점검(test) · 복사본에서는 안 보냄
- 처음 한 번: Supabase 새 프로젝트 → SQL Editor 에 `supabase/schema.sql` 붙여 넣고 Run → Project Settings › API Keys 의 Project URL 과 공개 키(publishable 또는 anon — **secret · service_role 키는 절대 넣지 말 것**)를 `game.js` 의 `STATS` 에 넣고 푸시
- 게임(공개 키)은 넣기만 할 수 있고 읽기 · 고치기 · 지우기는 못 합니다(RLS). 보기는 대시보드 Table Editor 나 SQL Editor 에서 `supabase/stats.sql` — 캐릭터 · 난이도별 판 수 · 클리어율, 몇 분에 · 무엇에 많이 쓰러지나, 많이 쓴 스킬, 날마다 판 수, 강화한 판 · 안 한 판(클리어율 · 버틴 시간). `up` 열은 예전 표라면 `schema.sql` 의 `alter table … add column if not exists up …` 한 줄을 SQL Editor 에서 Run(안 하면 판이 저장되지 않는다)

## 소리

파일 없이 웹 오디오로 직접 만든다(`game.js` 의 `SND`). 첫 클릭 · 키 · 터치에 켜진다. 오른쪽 위 소리 단추를 누르면 가운데 창에서 배경음 · 효과음 크기를 따로 조절한다(0 이면 끔, 이 브라우저에 기억). 게임 중에 열면 멈추고, 닫으면(닫기 · 바깥 · Esc) 이어서.

- 배경음악: 직접 지은 두 곡 — 일렉 팝(처음 화면 · 토벌, 16마디 — 4비트 킥에 출렁이는 베이스 · 아르페지오 · 리드), 세이렌(최종보스 · 검은 별똥별 — 네모파 칩튠). 일시정지하면 작아진다
- 토벌 중 일렉 팝은 같은 곡을 캐릭터마다 다른 악기로(`KIT`): 처음 화면 일렉 신스 · 치이카와 오르골 · 하치와레 어쿠스틱 기타 · 우사기 록 기타 · 모몽가 칩튠 · 쿠리만쥬 일렉 피아노 · 랏코 피리 · 시사 산신 · 카니 마림바
- 효과음: 맞힘 · 쓰러뜨림 · 경험치 · 레벨 업 · 보물상자 · 다침 · 보스 등장 · 검은 별똥별 · 끝
- 캐릭터 목소리: 캐릭터마다 높이 · 음색이 다른 삐약 소리(시작 · 레벨 업은 기쁘게, 다치면 아프게, 쓰러지면 울음). 원작 성우 음성은 쓰지 않는다

## 검색 · 공유

- `index.html` 머리말: 제목 · 설명 · 키워드 · canonical · robots, 공유 미리보기(Open Graph · X 카드), 아이콘, 검색 엔진용 구조화 데이터(JSON-LD `VideoGame`), 자바스크립트가 꺼진 곳을 위한 `<noscript>` 소개
- `og.png`(1200×630 공유 썸네일) · `icon-512.png` · `apple-touch-icon.png`(180) · `favicon.png`(64) — 게임 속 직접 그린 캐릭터로 `test/og.cjs` 가 만든다(그림을 고치면 다시 실행) 다시 만들면 index.html 의 `og.png?v=` · `favicon.png?v=` · `apple-touch-icon.png?v=` 숫자를 올린다(카카오톡 · X · 브라우저가 옛 그림을 붙잡고 있지 않게).
- SNS 홍보: `test/promo.cjs` 가 `promo/`(git 에 안 올림)에 이미지 3장(정사각 1080 · 세로 1080×1920 · 가로 1600×900)과 숏츠 영상 `shorts.mp4`(세로 1080×1920 · 30fps · 약 27초 — 제목 → 10분 → 20분 아노코 → 25분 세이렌 토벌 성공 → 주소, 게임 배경음을 OfflineAudioContext 로 그려 넣고 -16 LUFS)를 만든다. 게임을 한 프레임씩 직접 돌려 찍어 기기 속도와 상관없이 매끄럽다. 로컬 서버(8765) + `NODE_PATH=<playwright> FFMPEG=<libx264 ffmpeg> node test/promo.cjs`(FFMPEG 가 없으면 이미지만)
- `robots.txt`(사이트맵 위치) · `sitemap.xml`(내용을 바꾸면 `lastmod` 날짜를 고친다) · `site.webmanifest`(홈 화면에 추가할 때 이름 · 아이콘)

검색 등록(소유 확인 코드는 각 사이트에서 받아 `index.html` 머리말에 한 줄 넣는다)

1. 구글 서치 콘솔 — 속성 추가 → URL 접두어 `https://chii-ka-wa.github.io/` → 「HTML 태그」 → `<meta name="google-site-verification" content="…">` 를 넣고 푸시 → 확인 → 「Sitemaps」에 `sitemap.xml` 제출

3. 카카오톡 미리보기가 예전 것으로 보이면 — 카카오 개발자 「공유 디버거」에서 주소를 넣고 캐시 초기화
